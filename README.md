# effort_values

This was an attempt to make an effort value tracking tool for Pokemon that could be shared via bookmarks.
Sometimes, it's good to look back to see where you started.

## Features

* All of the Pokemon at the time (up to Arceus)
* One-click EV tracking with experience share
* Overly-dragging-centered interface
* Really bad code
* Sprites taken from somewhere, possibly Bulbapedia
* Still-working Bulbapedia links
